# Tarefas de HTML, CSS e JavaScript

Conjunto de exercícios web com uma página inicial que liga a cada tarefa.

| Página | Tema |
|---|---|
| `t1.html` | Formulário de contacto (nome, email, BI, número de estudante e mensagem) |
| `t2.html` | Mini pauta: notas por trimestre (P1, P2, MAC), média e situação do aluno |
| `t3.html` | Manipulação de texto com JavaScript: maiúsculas, minúsculas, inverter e limpar |

## Executar

Abra `index.html` no navegador. Não precisa de instalação nem de servidor.
